Short clips from livestreams

A personal desktop tool that turns long livestream recordings into short vertical clips.

What it does

  • Finds the most interesting moments of a livestream recording.
  • Cuts them into vertical 9:16 clips with captions and a credit to the original channel.
  • Sends each clip to the owner's own TikTok account as a draft (inbox), so the owner reviews and publishes it manually from the TikTok app.

Who uses it

The tool runs only on the owner's computer and is used only with the owner's own TikTok account. It is not offered to the public and has no user sign-up.

TikTok integration

It uses Login Kit to let the owner authorize their own account, and the Content Posting API to upload videos to that account's drafts. It requests only the user.info.basic and video.upload scopes.
